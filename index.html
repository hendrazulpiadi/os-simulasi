Langkah 1: Pilih Sistem Operasi Target

Setiap OS memiliki kriteria, arsitektur, dan skema partisi serta kebutuhan sistem yang berbeda.

  • Mode Boot: UEFI Only (TPM 2.0 + Secure Boot)
  • Skema Partisi USB: GPT
  • File System USB: NTFS
  • Format File ISO: Win11_23H2_Indo.iso (~5.2 GB)

Ubuntu Linux 24.04 LTS

64-bit (x64)
  • Mode Boot: UEFI / Legacy BIOS
  • Skema Partisi USB: GPT / MBR
  • File System Partisi OS: ext4, swap, EFI
  • Format File ISO: ubuntu-24.04-desktop.iso (~4.8 GB)
